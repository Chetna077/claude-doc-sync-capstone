# Verification Report — claude-doc-sync

## Environment

- Node.js: v24.19.0 (project requires `>=20` per `package.json` `engines`)
- OS: Windows 11 (tests run via Git Bash / mingw64)
- Test runner: `node --test` (Node built-in, no third-party test framework)

## Command

```sh
npm test        # unit + integration + CLI subprocess tests
npm run test:e2e   # Playwright test against demo.html
```

`npm test` resolves to `node --test "test/**/*.test.js"` — the glob is
scoped deliberately (see "Native Features Layer Addition" below) so the
Node test runner only picks up `*.test.js` files, not the Playwright
`*.spec.js` file living under the same `test/` tree.

## Manual CLI Verification

Ran the CLI directly against this project's own repository (not a fixture)
to confirm real-world behavior beyond the automated suite:

```sh
node bin/claude-doc-sync.js --template templates/project-doc.template.md --repo . --out /tmp/manual-check.filled.md
```

Output:

```
7 / 10 placeholders found.
```

Filled document correctly resolved `ProjectName`, `MainEntryPoint`,
`License`, `TestCommand`, `LastCommitDate`, and `LastCommitAuthor` from this
project's real `package.json` and git history, and correctly rendered
`Author`, `Dependencies`, and `DevDependencies` as `Not Found` (this
project genuinely has no `author` field and no dependencies of either
kind) — confirming the "verify, don't guess" behavior holds against a real
repo, not just fixtures.

## Native Features Layer Addition

A second round of work added a `.claude/` configuration layer (agents,
skills, hooks, instructions, settings) plus `CLAUDE.md`, `demo.html`, and
a Playwright end-to-end test — none of which change `src/`, `bin/`, or
`templates/`. This section records the re-verification done after those
additions:

- `demo-output.filled.md` was generated by actually running
  `node bin/claude-doc-sync.js --template templates/project-doc.template.md --repo . --out demo-output.filled.md`
  against this repository, and its real output (`7 / 10 placeholders
  found`) was used verbatim as the "After" content in `demo.html` — the
  demo page is not hand-written sample data.
- `@playwright/test` was added as the only devDependency; the tool itself
  still has zero runtime dependencies.
- `npm test`'s glob was narrowed to `test/**/*.test.js` specifically to
  keep the Node built-in test runner from also trying (and failing) to
  execute the Playwright `*.spec.js` file as a plain Node test.
- Both `npm test` (35/35) and `npm run test:e2e` (1/1) were re-run after
  all additions and are green, confirming nothing in the existing
  implementation was affected.

Implementation matches `requirements.md` and the resolver rules in
